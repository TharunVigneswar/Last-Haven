# Last-Haven

In this game, you need to survive as a colony and thrive. Choose from 3 game modes - Easy, Medium or Hard. 

How to install:
install the .py file and run it in your code editor like VS code or IDLE. Make sure to install pygame library by typing "pip install pygame" in your terminal

How to play:
